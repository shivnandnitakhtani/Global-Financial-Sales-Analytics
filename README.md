# Global Financial Sales Analytics & Forecasting System

An end-to-end Data Analytics and Machine Learning project focused on cleaning financial transaction data, building a predictive regression model for forecasting sales, and designing an interactive business intelligence dashboard.

## 🛠️ Tech Stack & Tools
* *Language:* Python 3.x
* *Libraries:* Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* *Business Intelligence:* Microsoft Power BI
* *Documentation:* WPS Office (PDF Architecture)

## 📂 Project Structure & Deliverables
* analysis.ipynb - Jupyter Notebook containing the full Python pipeline (Data Cleaning, EDA, and Machine Learning Modeling).
* financial_sales_cleaned.csv - The processed and clean version of the transactional dataset.
* Sales_Dashboard.pbix - Interactive Power BI dashboard showing monthly trends and KPI metrics.
* Project_Explanation_Report.pdf - Executive summary and strategic recommendations for stakeholders.

## 📊 Machine Learning Model Metrics
* *Algorithm:* Linear Regression Regressor
* *R-squared (R²) Score:* 0.7624 (Explains ~76.24% of operational variance)
* *RMSE:* 114,707.06
